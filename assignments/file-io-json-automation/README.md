# 📘 Assignment: File I/O and JSON Automation

## 🎯 Objective

Learn how to read from and write to files in Python, work with JSON data, and automate a simple data processing workflow.

## 📝 Tasks

### 🛠️ Read and Parse JSON Files

#### Description
Write a function that loads JSON data from a file and parses it into Python objects.

#### Requirements
Completed program should:

- Open a JSON file safely using a context manager.
- Parse the JSON into a Python dictionary or list.
- Access values from the JSON structure and print them in a readable format.

### 🛠️ Write Data to JSON Files

#### Description
Write a function that modifies data in Python and writes it back to a JSON file.

#### Requirements
Completed program should:

- Create or update a Python data structure.
- Write the data back to a JSON file with proper formatting.
- Preserve valid JSON syntax and include indentation for readability.

### 🛠️ Automate a Data Workflow

#### Description
Combine file reading and writing to automate a workflow, such as updating records or exporting filtered results.

#### Requirements
Completed program should:

- Read input data from a file.
- Process or filter the data based on a simple rule.
- Write the processed results to a new file.
- Confirm the workflow by printing a summary of what changed.
